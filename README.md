# Austin Gray — Creative Portfolio

A responsive, light-blue-forward portfolio website with a clean Y2K/editorial aesthetic, chrome star accents, and four primary navigation sections: Home, About Me, Portfolio, and Music.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser. No build step or package installation is required.

For a local development server, you can use VS Code's Live Server extension.

## Publish on GitHub Pages

1. Create a GitHub repository (for example, `austin-gray-portfolio`).
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. Open **Settings → Pages** in the repository.
4. Under build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your public website URL after deployment finishes.

## Personalize your site

- **Portraits and project images:** Search for `<img` in `index.html` and replace each image URL with your own image path, e.g. `assets/austin-portrait.jpg`.
- **Contact details:** Search for `austingray@email.com`, `@austin.gray`, and `/in/austingray` and replace them with your real links.
- **Project descriptions:** Edit the project cards and sample details in `index.html`.
- **Colors and typography:** Edit the CSS variables at the top of `styles.css`.

Images currently use remote Unsplash placeholders. Replace them with photos you own or have permission to use before launching the final portfolio.
